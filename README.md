# North Haven Barber Shop — Sample Website

Sample website I designed for North Haven Barber Shop, a barber shop in Calgary, Alberta, Canada.

- Services, prices, booking flow and mobile-first design with smooth scroll effects.
- Bookings via WhatsApp.

## View the site

Open `index.html` in a browser, or enable GitHub Pages on this repository to serve it live.
